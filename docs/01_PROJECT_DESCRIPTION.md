## Executive Summary

EcoMind AI is an intelligent campus sustainability management platform designed to help educational institutions monitor, forecast, and optimize electricity consumption across classrooms, computer laboratories, libraries, hostels, and administrative facilities.

By combining machine learning regression (RandomForestRegressor), unsupervised anomaly detection (IsolationForest), explainable decision-support analytics, RAG knowledge retrieval, and a conversational AI agent ("Ask EcoMind"), the platform transforms raw energy data into actionable sustainability recommendations.

---

## Key Deliverables Included
1. **Machine Learning Pipeline**: Real regression forecasting and IsolationForest anomaly detection models trained and saved via `joblib`.
2. **Explainable Insights & Recommendation Engine**: Rule-based decision support system generating targeted energy-saving advisories.
3. **Conversational AI Agent**: "Ask EcoMind" assistant that decouples analytics calculations from text generation to prevent AI hallucinations.
4. **RAG Knowledge Base**: Lightweight retrieval-augmented generation over campus energy policies and sustainability guidelines.
5. **Interactive Dashboard**: Full Streamlit web application supporting live data analytics, 4 interactive demo scenarios, forecasting tools, and impact calculators.
6. **Submission Documentation & Presentation Deck**: Deliverables following the 1M1B internship rubric.
